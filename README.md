SpaceX Rakéta Menedzser

A projekt egy egyoldalas webalkalmazás, amely a SpaceX nyilvános API-jából tölti be a rakéták adatait, majd lehetőséget biztosít azok kezelésére és összehasonlítására.

Megvalósított funkciók

- Rakétaadatok lekérése a SpaceX API-ból
- Mapper réteg használata a nyers API válasz feldolgozására
- 3 másodperces betöltési állapot megjelenítése
- Rakéták rendezése kilövési költség szerint
- Aktív és összes rakéta közötti szűrés
- Rakéták hozzáadása a flottához
- Rakéták eltávolítása a flottából
- A flotta teljes LEO teherbírásának számítása
- A flotta átlagos kilövési költségének számítása
- Két rakéta összehasonlítása táblázatos formában
- SpaceX stílusú sötét megjelenés

Telepítés

npm install,
npm run dev,
npm run build
